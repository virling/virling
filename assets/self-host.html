self-host

One binary. Your server.
Your data stays put.

Virling is a self-hosted alternative to Google Analytics that also reads your payments. It is open source under AGPLv3 and free to run yourself: download it, start it, add one tag to your site and connect a payment provider. Source on GitHub.

What you get

  • Revenue and revenue per visitor for every channel, page and country
  • The visits before each payment, from the payment provider back to the first click
  • Last non-direct or first-touch attribution, with a 30, 60, 90 or 365 day lookback
  • A tracking script of about 1.4 KB gzipped, with an optional cookieless mode
  • A read API, an MCP server and a CLI for your own tools

What it needs

  • Linux on x86_64 or arm64, macOS on Intel or Apple silicon, or Docker
  • A domain pointing at the server, behind your reverse proxy for HTTPS
  • Port 8080, and one data folder: SQLite for settings, DuckDB for events
  • No Postgres, no ClickHouse, no Redis

Install

One command picks the right build for your machine, checks its checksum, and on a Linux server sets up and starts the service, then prints the URL.

curl -fsSL https://virling.com/install.sh | sh

Or run the container:

docker run -d --name virling -p 8080:8080 -v virling-data:/data \
  -e VIRLING_BASE_URL=https://stats.example.com \
  ghcr.io/virling/virling:latest serve --app

The quickstart walks through adding your site, the script and a payment provider.
