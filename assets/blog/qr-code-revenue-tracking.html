Track QR code sales: which printed codes bring paying customers

By Devendra Variya, co-founder of Virling. Published 2026-11-17.

To track QR code sales, put UTM tags inside the URL the code opens, with utm_source=qr and the placement in the campaign, and make one code per placement. Point each code at a page on your site, store the visitor ID on each order, then join each order to the visit that came before it. You then see which scans turn into paying customers, and the revenue and revenue per visitor of each code. A scan count from a QR generator does not tell you this.

This guide is for stores and businesses that put QR codes on print: packaging and inserts, flyers, posters, menus, business cards, event banners and booth signs.

Why QR code scans show up as Direct

When someone scans a code, the phone's camera opens the URL in the browser. There is no page before it, so the visit arrives with no referrer. Analytics tools, Virling included, decide the channel from the referrer and the UTM tags. With neither, the visit is Direct, and so is the order that follows.

A tag fixes this because it travels inside the URL. With no referrer, Virling reads utm_source. qr is not one of the known social or search sources, so a tagged scan lands in the Referral channel, under its own source and campaign, instead of in Direct. If your Direct traffic rises the week a flyer goes out or an event takes place, untagged codes are a likely cause. Why Direct is your biggest traffic source covers the other causes, and the full rule order is in channels.

Step 1: add the script

Add the Virling script to the <head> of every page of your site. It records each visit with its referrer and UTM tags, and sets the first-party visitor ID that orders need later. On Shopify, it goes in your theme's theme.liquid; on WooCommerce, the Virling WordPress plugin adds it for you. The app's setup screen shows the exact tag for your site, and add the script covers where it goes.

Point every code at a page with the script, such as a product page, a collection or a landing page for the event. A code that opens a Stripe, Polar or Dodo payment link directly carries no visitor ID, so those sales come in as Unattributed.

Step 2: tag the URL inside each code

Make one code per placement, and give each placement its own campaign:

https://yourstore.com/?utm_source=qr&utm_medium=print&utm_campaign=qr-packaging-insert
https://yourstore.com/collections/spring?utm_source=qr&utm_medium=print&utm_campaign=qr-spring-flyer-2026-11
https://yourstore.com/expo?utm_source=qr&utm_medium=print&utm_campaign=qr-expo-booth-2026-11&utm_content=banner
  • utm_source=qr on every code, so all scans group under one source and stay out of Direct.
  • utm_medium=print, or another value you keep fixed. Do not use email or a paid medium such as cpc: those put the visit in the Email or Paid channel. Use a paid medium only if you want scans from a paid placement, such as a print ad, counted with your other ads.
  • utm_campaign names the placement: one value per code, lowercase, with hyphens. The Campaign tab groups visitors and revenue by this value, so this is the tag that gives you revenue per code. Add the month for anything you reprint, so each run is its own row.
  • utm_content tells two codes in the same placement apart, such as banner and table-card at one booth. Virling stores it with each visit; keep what you want to compare in the campaign so it shows up in reports.

One code per placement matters more for QR than for most channels. A printed code cannot be changed once it is out, and if the flyer, the packaging insert and the banner all open the same URL, their sales add up into one row for good. The UTM builder makes each link for you, and the UTM naming template keeps the values the same across codes and your other channels. More rules are in which UTM parameters to use.

Step 3: use a short redirect link

Every character in the URL makes the code denser, and a dense code is harder to scan when it is printed small, on a curved bottle or across a hall. A short link that redirects to the tagged URL keeps the code simple.

In Virling, open the Campaign tab on the Channels card, click + Tracked link, pick QR code as the place and type the page it should open. You get a short URL on your Virling server, such as https://stats.example.com/l/35b6cac, to put in the code. On each scan it redirects to the page with utm_source=qr, utm_medium=referral and the link's own campaign added, and keeps any tags the page URL already has. The Campaign tab lists it with its clicks, visitors and revenue. Make one tracked link per placement. See tracked links.

Do not delete a tracked link that is already printed: deleting it makes the short URL return 404 right away, and every code that uses it stops working. If you make codes with a separate QR generator that has its own redirect, put the full tagged URL as its target, so the tags still reach your site.

Step 4: connect your store or payment provider

Tags only get you visits. Revenue needs the orders and the visitor ID on each one. In the app, open your site, then Setup, then Connect payments, paste the key your provider needs and click Connect and backfill; see payments.

  • Shopify. Create a custom app with only the read_orders scope and paste its token. Then add the short theme snippet that stores the visitor ID on the cart, which Shopify copies onto the order. See Shopify and the Shopify docs.
  • WooCommerce. Create a read-only REST API key and paste it. Then add the short snippet that stores the virling_vid cookie on each new order. See WooCommerce and the WooCommerce docs.
  • Another checkout. Virling also reads Stripe, Paddle, Lemon Squeezy, Polar, Dodo Payments, Creem and RevenueCat, all listed on integrations. For a checkout you create on your server, pass the virling_vid cookie, for example as client_reference_id on a Stripe Checkout Session. Every case is covered in link checkout to visits.

Scan one of your printed codes with your phone, place a test order, then check that it appears on the Payments page with the code's campaign.

What to check when the numbers look wrong

  • Scans look small but Direct jumped after the print went out. Some codes open an untagged URL. Scan each one and look at the address it opens.
  • A code shows clicks but no visits. The page it opens may not have the script, or the scan was blocked by a content blocker. Check that the destination page records a pageview.
  • Visits but no revenue at all. Check the Matched revenue line under the Overview numbers. If a large share of revenue is unmatched, the visitor ID is not reaching the order. On Shopify and WooCommerce, check that the snippet is in place. See Unattributed revenue.
  • A buyer says they saw your flyer but the order is credited elsewhere. They may have read it without scanning and searched for you later. No analytics tool can count a code that was never scanned.
  • Visitors who block the script are not counted at all, so a code's real visitor number can be higher than what any analytics tool shows. Revenue still counts in your total, as Unattributed.

Frequently asked questions

How do I track sales from a QR code?

Put a UTM-tagged URL inside the QR code, with utm_source=qr and the placement in utm_campaign, and point it at a page on your site. Store the visitor ID on each order and use a tool that joins orders to visits. The Campaign tab then shows visitors and revenue per code.

Why do QR code scans show up as Direct?

A phone camera opens the scanned URL in the browser with no referrer. With no referrer and no tag, analytics tools count the visit as Direct. UTM tags travel inside the URL itself, so a tagged code is credited to the code.

Should every QR code be different?

Yes, one code per placement. A code on packaging, one on a flyer and one on an event banner should each carry their own utm_campaign. If they share a URL, their scans and sales add up into one row and you cannot tell which placement paid.

Can a QR code point straight to a payment link?

It can, but the sale cannot be credited. A Stripe, Polar or Dodo payment link opened from a QR code carries no visitor ID, so the payment is Unattributed. Point the code at a page on your site with the script, and let the buyer go to checkout from there.

Do long UTM tags make a QR code harder to scan?

A longer URL needs a denser code, which is harder to scan when printed small or far away. A short redirect link, such as a Virling tracked link, keeps the code simple and adds the tags on the scan.
