Why WooCommerce order attribution says Unknown

By Devendra Variya, co-founder of Virling. Published 2026-11-01.

TL;DR: Unknown means the order has no source type WooCommerce can name, usually because no attribution data was saved with it. Order attribution reads the visitor's source from cookies set in the browser, so anything that stops that script or its cookies, or stops the values reaching the order, ends in Unknown. So do most orders sent through the API. WooCommerce does not fill in missing data later, so the fixes only help future orders.

How WooCommerce order attribution works

Order attribution is built into WooCommerce. You can turn it on or off under WooCommerce, Settings, Advanced, Features. A script in the store records where each visitor came from, such as a referrer or UTM tags, in cookies that last for the browser session. At checkout WooCommerce copies those values onto the order and shows them as the order's origin. When the order has no source type it knows, the label is Unknown. Where UTM tags appear on the order is covered in WooCommerce UTM tracking.

Two things often blamed for Unknown show up under other labels. A buyer who comes back after the session cookies are gone gets the source of the new visit, often Direct. A tagged link whose tags are lost in a redirect, or whose landing page does not run the script, is also usually Direct, because a visit with no earlier record, tag or outside referrer counts as typed in.

How to test it

  1. Prepare. Put your gateway in test mode, or turn on Cash on delivery. Turn off browser extensions.
  2. Open a tagged link in a private window. Use https://yourstore.com/?utm_source=test&utm_medium=test, accept the consent banner, and check that the tags are still in the address bar.
  3. Read the value at checkout. In the same window, add a product and open checkout. In the browser console, run wc_order_attribution.getAttributionData().source_type. It should return utm.
  4. Place the test order the way a customer would.
  5. Look at the order. In WooCommerce, Orders, read the Origin column. Then open the order and find the Order attribution box, which lists origin, source type, medium, device type and session page views.
  6. Change one thing and repeat in a new private window: the delay and caching rules, the banner declined, then each express button and gateway.

Frequently asked questions

What does Unknown mean in WooCommerce order attribution?

It means the order has no source type WooCommerce can name, usually because no attribution data was saved with it. WooCommerce does not fill the data in later.

Why are WooCommerce orders Unknown even with UTM links?

The UTM tags are read by a script into cookies. If the script is delayed or blocked, the cookies are refused, or the checkout or payment button does not send the values, they never reach the order.

Do subscription renewals show as Unknown?

Only when the first order had no attribution or the subscription was created without one. WooCommerce Subscriptions copies custom fields from the first order to the subscription and then to each renewal, so a renewal normally repeats the first origin.

How do I turn on WooCommerce order attribution?

Go to WooCommerce, Settings, Advanced, Features and enable Order Attribution.
