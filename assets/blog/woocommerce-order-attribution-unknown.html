Why WooCommerce order attribution says Unknown

By Devendra Variya, co-founder of Virling. Published 2026-11-01.

TL;DR: Unknown means WooCommerce saved no attribution data with the order. Its order attribution reads the visitor's source from cookies set in the browser, so anything that stops those cookies or that script, or any order placed without a browser visit, ends up as Unknown. Data that was never saved cannot be recovered later, so the fixes only help future orders.

How WooCommerce order attribution works

Order attribution is built into WooCommerce. You can turn it on or off under WooCommerce, Settings, Advanced, Features. A script in the store records where each visitor came from, such as a referrer or UTM tags, in short-lived cookies. At checkout WooCommerce copies those values onto the order and shows them as the order's origin.

How to test it

  1. Open your store in a private window from a link with ?utm_source=test&utm_medium=test.
  2. Place a test order the way a customer would.
  3. Open the order in the admin and check the origin. If it says Unknown, turn off script delay and caching rules one at a time and repeat.

Frequently asked questions

What does Unknown mean in WooCommerce order attribution?

It means WooCommerce saved no attribution data with the order, so it cannot say which source brought the buyer. It is not a display error, and the data cannot be filled in later.

Why are WooCommerce orders Unknown even with UTM links?

The UTM tags are read by a script into cookies. If the script is delayed or blocked, the cookies are refused, or the checkout runs outside the store's pages, the values never reach the order.

Do subscription renewals show as Unknown?

Renewal orders are created without a store visit, so they carry no fresh attribution. A tool that links renewals to the first payment keeps their original channel.

How do I turn on WooCommerce order attribution?

Go to WooCommerce, Settings, Advanced, Features and enable Order Attribution.
