Do software directories bring paying customers? How to measure it

By Devendra Variya, co-founder of Virling. Published 2026-11-17.

To find out whether a software directory brings paying customers, tag the website link on each listing with the directory's name in utm_source and utm_campaign, carry the visitor ID into checkout, and join each payment to the visit that came before it. Then compare paying customers and revenue per visitor for each directory over 90 days. Listing views, upvotes and badge clicks do not tell you this.

Most SaaS founders submit their product to a long list of directories and launch sites in the first months. Some listings are free, some cost money, and all of them take time to write and keep up to date. Whether a listing is worth it comes down to one question: did anyone who clicked through from it become a customer, and how does that compare with your other listings and your site average?

How a directory click is credited

Virling gives every session one channel, from its first pageview. A click from a directory can be credited in two ways.

  • The referrer. A click from a listing in a web browser usually arrives with the directory's host as the referrer. producthunt.com and indiehackers.com are known community hosts, so their visits land in the Communities channel. Any other directory host lands in Referral and shows under its own name in the Source tab. The referrer is a host only, so it cannot tell two listings on the same site apart.
  • A UTM tag. Some directories open links with no referrer, or set a policy that hides it. With no referrer, Virling reads utm_source, and when that is missing it reads ref. producthunt and indiehackers are known Communities sources; any other value lands in Referral. With no referrer and no tag, the visit is Direct.

A utm_medium of cpc, paid or similar moves the visit to Paid, and email or newsletter moves it to Email, before the referrer is checked. The full rule order is in channels, and you can paste any listing link into the traffic source checker to see where it lands.

Tag each listing link per directory

Directories that land in Referral show up one by one in the Source tab, but only when the referrer survives. Tagged visits with no referrer have no host to group by, so put the directory's name in the campaign as well. One value per directory gives you one row per directory in the Campaign tab, whatever the referrer did:

https://yourdomain.com/?utm_source=producthunt&utm_medium=referral&utm_campaign=producthunt
https://yourdomain.com/?utm_source=indiehackers&utm_medium=referral&utm_campaign=indiehackers
https://yourdomain.com/?utm_source=exampledirectory&utm_medium=referral&utm_campaign=exampledirectory
  • utm_source names the directory, lowercase, one word. Use producthunt and indiehackers as written so those visits stay in Communities.
  • utm_medium=referral on all of them. It keeps the channel decided by the referrer or source. If you pay for a featured slot and want it counted as Paid, use cpc on that link only.
  • utm_campaign repeats the directory's name. Keep it the same on every link you place on that directory, so a year from now it is still one row.

The UTM builder makes each link, and which UTM parameters to use covers the naming rules. If a directory strips query strings from the URL you submit, use a tracked link instead: in Virling, open Links, set the source to the directory's name, the channel to Referral, and the page it should open. The short link adds the tags on the click, and its id becomes the campaign, so make one link per directory. See tracked links.

Set up Virling

  1. Add the script. Put the Virling tag in the <head> of every page, including the pages your listings link to. See add the script.
  2. Connect a payment provider. Virling reads payments from Stripe, Paddle, Lemon Squeezy, Polar, Dodo Payments, Creem, RevenueCat, Shopify and WooCommerce; all of them are on the integrations page.
  3. Pass the visitor ID into checkout. If you use Stripe Payment Links, Polar checkout links or Dodo Payments links, the script adds the ID on click. For a checkout you create on your server, pass the virling_vid cookie, for example as client_reference_id on a Stripe Checkout Session. See link checkout to visits. Without this step you get visits but no revenue.
  4. Update your listings. Replace the plain website URL on each listing with its tagged link, then click one yourself and check that the visit shows on the dashboard with the right source and campaign.

A worked method: 90 days, one row per directory

Directory traffic is small and steady, and buyers who find you there often sign up, try the product and pay weeks later. Judge it over a long range. With the default model, last non-direct, a payment goes to the latest visit that was not Direct inside the lookback window, 90 days by default, so a buyer who clicked your listing and later typed your URL is still credited to the directory. See the model and lookback window.

  1. Pick Last 90 days in the date picker, or a custom range that starts when you tagged your listings.
  2. On the Channels card, switch to the Campaign tab. Each directory you tagged is a row with visitors, revenue and revenue per visitor, and a chip that compares it with your site average: green above it, red below it.
  3. Click a directory's row to filter the whole page. The New customers number at the top is now the paying customers that directory brought in the range, and the revenue chart shows when its money arrived.
  4. Write down visitors, new customers, revenue and revenue per visitor for each directory, then clear the filter and note your site's revenue per visitor for the same range.
  5. Switch to the Source tab and open Referral and Communities to see untagged clicks by host, such as listings you forgot to update or sites that copied your listing.
  6. Open a payment from the Payments page to see the buyer's journey: every visit before the payment, with the credited one marked.

Then read the table. A directory with paying customers and revenue per visitor near or above your average is worth keeping up to date. One with visitors and no customers after 90 days is sending lookers. One with no visitors at all is a listing nobody sees. For a paid listing, put the directory's visitors, revenue and price into the revenue per visitor calculator to see its return and the revenue per visitor it needs to break even. What is revenue per visitor explains why it is the number to compare.

Launch sites follow the same method with a different shape: a burst of visitors in a day or two, and payments that arrive as trials end. Product Hunt launch revenue covers that case step by step. Revenue from a Hacker News post does the same for a Show HN. For the store and plugin side, such as a Shopify app or a Chrome extension, see do app marketplace listings bring paying customers.

What to check when the numbers look wrong

  • A directory shows visitors in the Source tab but not in the Campaign tab. The listing still has the plain URL, or the directory removed the query string. Update the link or use a tracked link.
  • One directory is split across rows. The campaign was spelled differently on different links. Pick one value and keep it.
  • Visits but no revenue at all. Check the Matched revenue line under the Overview numbers. If a large share of revenue is unmatched, the visitor ID is not reaching checkout. See Unattributed revenue.
  • A customer says they found you on a directory but the payment is credited elsewhere. A later non-direct visit took the credit, or they paid from another device. Switch the model to first touch in Site settings to see which channels introduce buyers; history is recomputed, and you can switch back.
  • Visitors who block the script are not counted at all, so a directory's real visitor number can be higher than what any analytics tool shows. Their revenue still counts in your total, as Unattributed.

Frequently asked questions

Are SaaS directories worth it?

Some are and many are not, and the only way to know for your product is to measure it. Tag each listing link, pass the visitor ID into checkout, and compare paying customers and revenue per visitor by directory over 90 days with your site average.

How do I track signups and payments from a directory listing?

Put utm_source and utm_campaign set to the directory's name on the website link of the listing, add the tracking script to your site and pass the visitor ID into checkout. Each directory is then a row in the Campaign tab with visitors, revenue and revenue per visitor.

Which channel do directory visits land in?

In Virling, visits from producthunt.com and indiehackers.com, or tagged producthunt or indiehackers, are in Communities. Any other directory is Referral and shows under its own host. A link tagged with a paid medium such as cpc counts as Paid.

Why do some directory clicks show up as Direct?

Some directories open links with no referrer, or set a policy that hides it. With no referrer and no tag, the visit is Direct. A utm_source on the listing link keeps it credited to the directory.

How long should I measure a directory before judging it?

About 90 days. Directory traffic is small, and buyers often pay weeks after their first visit, when a trial ends. Keep the lookback window, 90 days by default, longer than your trial plus decision time.
