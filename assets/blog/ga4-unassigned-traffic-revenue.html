GA4 unassigned traffic and (not set): find the revenue behind it

By Devendra Variya, co-founder of Virling. Published 2026-11-25.

GA4 unassigned traffic is made of visits that match none of Google’s channel rules, for example because a link has a utm_medium the rules do not know. (not set) is different: Analytics received nothing for that field. (direct) / (none) is a visit with no clear referral source. Fix the medium for the first, the tag setup for the second and your links for the third. To see what those visits paid, join each payment to the visitor’s visits instead of reading the channel name.

What each label means in Google Analytics 4

Each label is about missing or unrecognised information.

  • Unassigned is a channel. Google calls it the value used “when there are no other channel rules that match the event data” (source: Google, Default channel group). The source and medium can be perfectly filled in.
  • (not set) is a placeholder for any dimension. Google says Analytics uses it “when it hasn’t received any information for a dimension” (source: Google, What the value (not set) means). In the session source / medium it often travels with Unassigned.
  • (direct) / (none) is a source and a medium. Google says it “represents website traffic that doesn’t have a clear referral source” (source: Google, Understand (direct) / (none) traffic). The default rules put it in the Direct channel, so it is not Unassigned.

To tell them apart, open Reports, then Acquisition, then Traffic acquisition. Its default dimension is the session default channel grouping, and session source / medium is among its dimensions (source: Google, Traffic acquisition report). If the Unassigned rows are (not set), fix the tag setup first: new UTM tags do not bring back a missing session_start.

utm_medium values outside the default channel groups

Checked on 2026-11-25 against Google’s default channel group page. Upper and lower case make no difference to these rules, but spelling does. No rule on that page accepts a medium in the first column. To test a link of your own, paste it into the GA4 channel group checker, which shows the default channel it gets and the rule that decided it.

Three details of the rules explain most surprises:

  • The source can rescue a bad medium. Organic Social accepts a source on Google’s list of social sites or a social medium. So facebook / ads is not Unassigned. It counts as Organic Social, with your unpaid posts, which is harder to notice.
  • Paid is a pattern. A medium is paid when it contains cp, starts with paid, or is exactly ppc or retargeting. So paid-social matches and social-paid does not.
  • Some values must be exact. audio and sms are exact matches, so sms-campaign is not SMS unless the source is sms.

The default channels cannot be edited. If you need print or event, an Editor can open Admin, then Channel groups under Data display, and make a custom group with rules on source and medium. Google says it can be applied to reports retroactively, so it can also sort the links you cannot change (source: Google, Custom channel groups). For new links, see utm_source vs utm_medium, and run a list through the UTM checker to find missing tags, capitals and spaces. It does not test a medium against Google’s rules; the table does.

In Virling, Paid is cpc, ppc, paid, paidsearch, paid_social or paidsocial, so cpc and paid_social work in both. retargeting and display are not on that list.

How to see what those visits paid

Fixing a medium cleans up the channel names. It does not say whether the visitors bought. The Traffic acquisition report has a total revenue column, but it is built from the purchase events your site sends, and they can differ from what your provider took; see why GA4 revenue does not match Stripe. A join from payments to visits starts from the money:

  1. Record the visit. Add the Virling script to every page visitors land on. It keeps the landing page, referrer and UTM tags with a visitor ID.
  2. Pass the visitor ID into checkout. Follow link checkout to visits for your payment provider.
  3. Match each payment. Virling finds that visitor’s visits inside the lookback window, 90 days by default, and credits one. The default model is the latest visit that was not Direct.
  4. Read it by link. The Campaign tab lists the top utm_campaign values with their visitors and revenue, so a link with an odd medium can still have a row if it names a campaign.

Virling has no Unassigned channel. Every visit gets one of eight: Paid, Email, AI, Organic search, Communities, Social, Referral or Direct. A medium it does not know is ignored when there is a referrer or a source; with neither, the visit is Referral, unless an app Virling knows names itself. So acme-agency / partner with no referrer is Referral. The order of the rules is in how channels are decided.

Direct and Unattributed are different things

Neither is the same as Unassigned. Direct is a channel of visits: there was a visit, and it carried nothing to sort it by. Unattributed is a payment that is not credited to any visit. It still counts toward revenue, and charts list it last.

With the default model, a payment is credited to Direct only when every visit in the window was Direct. A renewal takes the credit of the customer’s first payment. If checkout cannot carry the ID, Stripe, Shopify and WooCommerce payments can be matched by email. Frequently asked questions

What is unassigned traffic in GA4?

Traffic that matches none of the rules in the default channel group. A common reason is a utm_medium that the rules do not know, such as partner or newsletter, on a source that is not on one of Google’s lists. A session with no session_start event is also shown as Unassigned.

What is the difference between Unassigned and (not set)?

Unassigned is a channel: no channel rule matched the visit. (not set) is a placeholder in any dimension, used when Analytics received no information for it. A session whose source and medium are (not set) can be shown as Unassigned.

Is (direct) / (none) the same as Unassigned?

No. (direct) / (none) is the source and medium of a visit with no clear referral source, and the default rules put it in the Direct channel. Unassigned means no rule matched, Direct included.

Which utm_medium values avoid Unassigned?

Values that a default rule accepts, such as email, cpc, paid_social, social, referral, affiliate, display, audio and sms. Upper and lower case make no difference to the default channel rules, but spelling does.

Can I change Unassigned traffic after the visit?

You cannot edit the default channel group. A custom channel group can sort the same source and medium values into your own channels, and Google says it can be applied to reports retroactively. It cannot add a source that was never received.

Is Unattributed in Virling the same as Unassigned in GA4?

No. Unassigned is a visit that no channel rule matched. Unattributed is a payment that is not credited to any visit, most often because no visitor ID reached checkout. Virling has no Unassigned channel.
