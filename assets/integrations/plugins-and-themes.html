Plugin sales attribution for plugin and theme sellers.

Buyers of a WordPress plugin, theme, template or code license usually find it in your docs, a marketplace listing, a blog post, a newsletter or a social post, then buy on your own site. Virling joins each license sale and renewal to the visit that came before it, so the dashboard shows which of those channels brought the money, not just the downloads. Add the script to your marketing site, tag the links in your free-version listings and readme files, and connect Paddle, LemonSqueezy, Polar, Creem or Stripe.

A plugin buyer rarely pays on the first visit. They install the free version, read the docs, open a support thread and come back when a client project needs the pro features. Virling credits each payment to a visit before it, by default the latest visit that was not Direct inside a 90-day lookback window, and you can switch the site to first touch to credit the visit that introduced the buyer.

Where plugin buyers come from

Every session gets one channel from its first pageview. The places plugin and theme buyers come from land in different ones:

  • Marketplace and free-version listings: wordpress.org and other directories are not on a known host list, so clicks land in Referral under their own domain.
  • Your blog and docs: visits that start there keep the channel that brought them to the post, such as Organic search or AI. Pages on your own domain and its subdomains never change the channel.
  • Newsletters: a link tagged utm_medium=newsletter or email lands in Email.
  • Social posts: clicks from known social hosts land in Social.
  • Readme files, the WordPress admin screen and downloaded files: often no referrer and no tag, so they are Direct unless you tag the link.

Set it up in three steps

1. Add the script to your marketing site

Put the Virling tag on the site where buyers land and check out. On WordPress, use the Virling plugin or paste the tag in your theme's header; the walkthrough is in WordPress revenue tracking. With data-site set to your domain, docs on docs.example.com count for the same site and share the visitor ID cookie. See Add the script.

2. Tag the links in listings and readme files

Links in a free-version listing, a readme, an upgrade notice or a settings screen carry no useful referrer. Give each one utm_source and its own utm_campaign, or create a tracked link in Virling: a short URL that adds the tags for you and shows the clicks, visitors and revenue it brought. The Campaign tab then splits the listing from the readme and the upgrade notice.

3. Connect your payment provider

Pass the visitor ID into checkout and connect the provider with a read-only key. Payments from the last 90 days are imported on the first run, then new ones every minute, and refunds lower a payment's revenue.

  • Paddle: virling_vid in the transaction's custom data, passed as customData with Paddle.js. Docs.
  • LemonSqueezy: the visitor ID as checkout custom data; the script adds it to plain checkout links. Docs.
  • Polar: checkout links need no code; checkout sessions take it in metadata. Docs.
  • Creem: the visitor ID in checkout metadata. Docs.
  • Stripe: Payment Links get it from the script; Checkout Sessions take it as client_reference_id or metadata. Docs.

License renewals

A yearly license billed as a subscription renews without a visit. Virling marks the renewal and gives it the channel, referrer and campaign of the customer's first payment, so a listing that sold a license keeps the credit for every renewal. See Renewals. Merchant of record fees differ by provider; compare them with the merchant of record fee calculator.

Frequently asked questions

Why does a click from my wordpress.org listing show as Referral?

wordpress.org is not on the community, search, social or AI host lists, so a click from a plugin or theme listing lands in Referral and shows under its own domain in the Source tab. Add utm_source and utm_campaign to the link, or use a tracked link, to tell the listing apart from your support forum or readme.

How do I track links from inside the plugin, its readme or the dashboard of a free install?

A link opened from a WordPress admin screen, a readme or a downloaded file often arrives with no referrer, so it counts as Direct. Tag those links with utm_source and one utm_campaign per placement, or create a tracked link in Virling, and the visit keeps its source.

Are license renewals credited to the channel that sold the first license?

Yes, when the renewal is billed as a subscription by Paddle, LemonSqueezy, Polar, Creem or Stripe. Virling detects the renewal and copies the channel, referrer and campaign of the customer's first payment. A new one-time purchase by the same buyer is a new sale credited from its own visitor ID, except on Creem, which counts any later payment of a customer as a renewal.

Which payment providers work for plugin and theme sales?

Paddle, LemonSqueezy, Polar, Creem and Stripe, each with a read-only key. Pass the visitor ID into checkout. Plain Stripe Payment Links, Polar checkout links and LemonSqueezy checkout links on a page that runs the script get it added by the script itself.

Does it work if my marketing site runs on WordPress?

Yes. Add the script with the Virling WordPress plugin or in your theme's header. The plugin skips logged-in administrators by default, so test from a private window.
