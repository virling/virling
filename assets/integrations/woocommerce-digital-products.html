See which channel sells your WooCommerce downloads.

For WooCommerce stores that sell ebooks, templates, presets, courses and other digital products. Virling ties each download order to the channel, campaign and post that brought the buyer, so you see which launch post, newsletter or search result brought the money, not just the clicks. WooCommerce records who bought a download and how much they paid, but not always the visit that brought them: its own order attribution can mark orders as Unknown. Virling joins the two: a visitor ID set when someone lands, saved on the order at checkout, and read from the order with a read-only key.

What you get

  • Each download order credited to a channel. Orders are imported and joined to the visits before them. Every visit gets one channel from its first pageview: Paid, Email, AI, Organic search, Communities, Social, Referral or Direct. By default an order goes to the latest visit in the last 90 days that was not Direct.
  • Revenue per source, campaign and landing page. The dashboard lists visitors, revenue and revenue per visitor for each channel, source, campaign and landing page, so a post that sent many visitors and no sales stands apart from a small one that paid.
  • Posts and newsletters measured by sales. Share a tracked link or a link with UTM tags in each post, newsletter or bio, and the Campaign tab and Links show the revenue each one brought.
  • Refunds taken off. Each order's refunds lower its revenue. Orders from the last 60 days are read again every 6 hours, so later refunds show up.

Set it up

  1. Add the site. Click + Add a site, enter your store's domain and paste the script before </head> on every page. Leave cookieless mode off: without the virling_vid cookie there is no visitor ID for the order to carry.
  2. Create a read-only key. In WordPress, open WooCommerce, Settings, Advanced, REST API, add a key and set Permissions to Read. In Virling, paste the consumer key and the consumer secret joined by a colon, as ck_...:cs_..., with your store's address. The store must be reachable over https, with pretty permalinks on so /wp-json/wc/v3/ answers. Orders from the last 90 days are imported on the first run, then new ones every minute.
  3. Save the visitor ID on each order. Add this to your theme's functions.php, or to a snippets plugin. It covers the classic and the block checkout.
add_action('woocommerce_checkout_create_order', 'virling_vid_on_order');
add_action('woocommerce_store_api_checkout_update_order_from_request', 'virling_vid_on_order');
function virling_vid_on_order($order) {
  $vid = $_COOKIE['virling_vid'] ?? '';
  if (preg_match('/^[A-Za-z0-9-]{8,64}$/', $vid)) $order->update_meta_data('virling_vid', $vid);
}

What to know

  • Orders placed before the snippet was added have no visitor ID and are Unattributed. They still count toward revenue.
  • A buyer who pays without first visiting a page that runs the script has no visit to credit and is Unattributed.
  • Processing and completed orders count as paid, failed and cancelled ones as failed. Pending and on-hold orders wait until they are paid.
  • Guest orders have no customer ID, so each counts as its own customer.

Frequently asked questions

Which channel sells my WooCommerce downloads?

Connect your store to Virling with a read-only REST API key and add the snippet that saves the virling_vid cookie on each order. Each download order is then credited to the visit before it, with its channel, source, campaign and landing page, and the dashboard shows revenue per channel.

How do I see which post or newsletter brought a download sale?

Share a tracked link or a link with UTM tags in each post, newsletter or bio instead of your plain URL. Visits from it carry those tags, so the Campaign tab, and Links for tracked links, show the revenue each one brought.

Are refunded downloads taken off?

Yes. Each order's refunds lower its revenue. Orders from the last 60 days are read again every 6 hours, so later refunds show up.

Why are some WooCommerce download orders Unattributed?

Orders placed before the snippet was added have no visitor ID, and a buyer who pays without first visiting a page that runs the script has no visit to credit. Those orders are Unattributed but still count toward revenue.
