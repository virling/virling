integrations / woocommerce for agencies

Show each WooCommerce client which channel drives their sales.

For agencies that build and market several client WooCommerce stores. Virling ties every order to the channel and campaign that brought the buyer, on a separate site per client, and gives each client a branded report they open without a login. Open source under AGPL, hosted or self-hosted.

Clients ask one question: which channel paid. WooCommerce records the order, and your ads, emails and posts bring the visit, but the two rarely meet. Virling joins them for each client store, so the answer comes from their own orders.

What your agency gets

  • One site per client store. Each client domain has its own script and its own WooCommerce connection, so every client's revenue stays on their site. Sites with the same client name are grouped in the site switcher and on All clients, with visitors and revenue over the last 30 days and a total per client.
  • Orders by channel and campaign. The Channels card lists visitors, revenue and revenue per visitor for each channel, with the sources and UTM campaigns behind it. Payments lists every order with the channel it was credited to. Refunds lower an order's revenue, and WooCommerce Subscriptions renewals keep the channel of the first payment.
  • Sharing without logins. A client link opens a site's report with your agency name, logo and colours, and can be revoked at once. A weekly email sends the same report to up to 10 client addresses.
  • Public dashboard. A read-only page anyone can open without signing in, which never shows emails or customer IDs, for clients who want to share their numbers.
  • API and MCP. One API key lists every client site and reads each one, and the same key connects an AI assistant through the MCP server to ask which channel paid.
  • Team members for your own staff, who see and manage every site on the account.

Set up a client store

  1. Add the client site. Click + Add a site, enter the client's domain and timezone, and set their name under Client in site settings.
  2. Install the script. Paste the site's tag before </head> on every page of the store. Add the short snippet from the WooCommerce integration to the theme's functions.php, or a snippets plugin, so every new order stores the visitor ID. It covers the classic and the block checkout.
  3. Connect WooCommerce. In the client's WordPress, open WooCommerce, Settings, Advanced, REST API, and add a key with Read permission. Paste the consumer key and secret as ck_...:cs_... with the store's https address into the site's payment setup. Orders from the last 90 days are imported, then new ones every minute.
  4. Share a client view. Under Client report in site settings, add your branding, then create a client link and send it. Turn on the weekly email to send the report on a schedule.

Tag every ad, email and post link with the UTM builder, so each campaign shows up by name instead of as Direct; see WooCommerce UTM tracking.

Monthly client reports

The client report and weekly email cover each week, with one plain line per channel against the week before. For a monthly review, pick the month as the dashboard range, read revenue and revenue per visitor from the Channels card, and open orders in Payments to show the journey behind a sale. Enter the client's monthly spend per channel in site settings and Profit by channel shows spend, revenue, profit and return per dollar.

The client marketing report template lays those numbers out in the order clients read them, and how to prove marketing ROI to clients walks through the monthly method. Download PDF on the report saves the page to attach to your own deck.

Open source

Virling is open source under AGPLv3, and the code is on GitHub. Use the hosted service, or self-host it on your own server with every feature. In a load test on 2026-10-31, in a container limited to one vCPU and 1 GB of RAM, it ingested 100,000 pageviews at 2,829 a second with none failed, and answered dashboard queries at 0.6 to 7.6 ms median.

Frequently asked questions

How do agencies show WooCommerce clients which channel drives sales?

Add one Virling site per client store, install the script and the functions.php snippet that saves the visitor ID on each order, and connect the store with a read-only REST API key. Each order is tied to the channel and campaign of the visit before it, and the client sees it through a report link without a login.

Does each client store need its own setup?

Yes. Each client domain is its own site with its own script tag and its own WooCommerce connection, so every client's orders and revenue stay on their site. Sites with the same client name are grouped under All clients.

Can my clients see their numbers without a Virling account?

Yes. A client link opens that site's report without signing in, with your agency name, logo and colours. You can revoke it at any time, and you can also email the report every week.

Can Virling change anything in a client's WooCommerce store?

No. The REST API key is created with Read permission only. Virling never creates, changes or refunds anything.
