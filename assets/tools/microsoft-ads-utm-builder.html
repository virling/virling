Microsoft Ads tracking template and UTM builder

Final URL suffix or tracking template

Both fields accept the same URL parameters, which Microsoft Advertising replaces with details of the click. They do different jobs:

Final URL suffixTracking template
What you enterParameters only, such as utm_source=bingA whole URL with a parameter that inserts the final URL, such as {lpurl}
What it doesAdds the parameters to the end of the landing page URLBuilds the URL from the template, which can also go through a tracking service
What it cannot hold?, & or # at the start, or {lpurl} anywhereMore than 2,048 characters
If levels differThe lowest level is used, levels are not combinedThe lowest level overrides the ones above

For UTM tags, use the suffix. Microsoft says parameters in it are always sent to the landing page. Use the template if a tracking service needs it, or if automatic UTM tagging is on for your account. Microsoft recommends putting {lpurl} at the beginning of the template, because elsewhere the final URL is escaped. A template without {lpurl} or a similar parameter breaks the landing page URL. Fill in one field with these tags, not both, or they can be sent twice.

Sources, all read on 2026-11-25: Microsoft Advertising help, Using a final URL suffix, Create an account tracking template and What tracking or URL parameters can I use?; Microsoft Advertising API docs, URL Tracking with Upgraded URLs.

The names and what they return are from Microsoft Advertising help, What tracking or URL parameters can I use?, read on 2026-11-25. The last column is our mapping, and the one this builder uses.

The word after the colon in {keyword:default} is the text Microsoft uses if the keyword would make the URL too long. The builder writes {keyword:none}, so a click that hits the limit shows as none. The help page only says that spaces in keywords are encoded, so prefer campaign and ad group names without spaces or symbols, or tick the IDs.

For Performance Max, Microsoft has no asset group parameters. It says to use {AdGroup} and {AdGroupId} to get the asset group name and ID.

How automatic UTM tagging behaves

Microsoft Advertising can add UTM tags itself, separately from the msclkid. The setting is under Settings, Account level options, Auto-tagging of UTM. You choose to replace all existing tags, which removes yours and adds Microsoft’s, or to keep your tags and add the missing ones. The API docs describe three states, off, preserve and replace, and say a new account defaults to off if no state is set (AutoTagType and AdvertiserAccount).

The choice checks the UTM tags in the tracking template. Microsoft warns that tags you add by hand in the final URL or the suffix, combined with automatic tagging, can be duplicated in some circumstances. So pick one of these:

  • Automatic tagging off. Paste the suffix. This is the simplest setup.
  • Automatic tagging on, with keep. Paste the template instead, and test the result.
  • Automatic tagging on, with replace. Your own tags are removed, so this builder will not help until you change the option.

Microsoft also lists a newer format that sets the tags by ad type, and notes that not everyone has it yet. The last column shows what the medium does in Virling:

A visit whose medium is not on the paid list is sorted by its referrer first, then by utm_source. Sources: Microsoft Advertising help, How do I add UTM tags to my landing page URL?; the API docs linked above, all read on 2026-11-25.

Where to paste it in Microsoft Advertising

  1. For the whole account, hover over Campaigns in the left menu and select Settings, then Account level options. Paste into Final URL suffix or Tracking template and save.
  2. For one campaign, open the campaign, select Settings, and paste the suffix under Campaign URL options.
  3. Do not put a question mark in front of the suffix.
  4. If both levels are set, only the lowest level is used. A campaign suffix has to repeat every tag you still want from the account suffix.
  5. Check the setup with Microsoft’s URL test tool, then open the tested URL and check that the tags are still in the address bar once the page has loaded. A redirect on your own site can drop them.

Because {Campaign} fills in the name of each campaign, one suffix on the account can cover all of them. Microsoft recommends setting the template on the account too, so a change is made in one place. Steps from Using a final URL suffix and Create an account tracking template, read on 2026-11-25.

A worked example

With the defaults above, the suffix is utm_source=bing&utm_medium=cpc&utm_campaign={Campaign}&utm_content={AdGroup}&utm_term={keyword:none}. The template is the same text after {lpurl}?.

If the final URL is https://example.com/pricing, the campaign is brand-search, the ad group is pricing and the keyword is analytics, the visitor lands on https://example.com/pricing?utm_source=bing&utm_medium=cpc&utm_campaign=brand-search&utm_content=pricing&utm_term=analytics. With auto-tagging of the msclkid on, which is the default for a new account, Microsoft also adds an msclkid (AccountProperty, read on 2026-11-25). The preview leaves it out because its value only exists for a real click.

What Virling reads from these tags

Virling reads utm_source, utm_medium, utm_campaign, utm_content and utm_term from the landing URL, and not the platform’s click ID, the msclkid. Leave the click ID on for Microsoft and add the UTM tags for Virling. Parameters sent under their own name, such as device or matchtype, are for other tools: Virling does not store them.

The builder defaults to utm_medium=cpc so the visit is Paid. The values cpc, ppc, paid, paidsearch, paid_social and paidsocial all count as Paid and are checked before the referrer. Without one of them, a click from bing.com is sorted as Organic search, next to your unpaid visits. The full rules are in how channels are decided.

The campaign tag is the one to get right, because Virling groups revenue by it. If you rename a campaign, later clicks carry the new name and become a second row. Microsoft Ads revenue tracking shows how to go from the tag to the payment, and Bing revenue tracking covers the unpaid clicks.

questions

Microsoft Ads tracking template FAQ

What should a Microsoft Ads tracking template for UTM tags look like?

Start with {lpurl}, then a question mark, then the tags joined with an ampersand: {lpurl}?utm_source=bing&utm_medium=cpc&utm_campaign={Campaign}. If the final URL already has a question mark, Microsoft Advertising replaces the one in the template with an ampersand.

Should I use the final URL suffix or the tracking template?

For UTM tags alone, the suffix is the simpler field: it holds only parameters and they are always sent to the landing page. Use the template if a tracking service needs it, or if you keep automatic UTM tagging on, because Microsoft says the keep or replace choice checks the tracking template. Do not put the same tags in both.

Is there a parameter for the campaign name in Microsoft Ads?

Yes. {Campaign} returns the name of the campaign and {AdGroup} the name of the ad group, so one suffix on the account can name every campaign. {CampaignId} and {AdGroupId} return the IDs instead.

Does automatic UTM tagging overwrite my own tags?

It depends on the option you pick. Replace removes the UTM tags you have and adds Microsoft's. Keep leaves yours and adds the ones that are missing. Microsoft warns that tags in the final URL or the suffix can be duplicated when automatic tagging is on.

Does Virling read the msclkid?

No. Virling reads utm_source, utm_medium and the other UTM tags, not the msclkid. Leave it on for Microsoft's own conversion tracking and add UTM tags to the same ads.

Why do my Microsoft Ads clicks show as organic search?

The landing URL had no paid medium. Without one, Virling sorts a click that arrives from bing.com by its referrer, which is Organic search. With utm_medium=cpc the visit is Paid, because the medium is checked before the referrer.
