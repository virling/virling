Getting good answers

  • Name a range. The tools take today, 7 days, 30 days, 90 days, 12 months, all time or two dates.
  • Name the site when your account has more than one, as in the agency questions. Replace client.com with the client’s domain.
  • Ask about revenue, not spend. Virling knows visitors, payments and revenue. It does not return ad spend or search impressions, so ROAS and cost per click are not answers it can give.
  • Ask for the path. When a number looks wrong, ask for the payments behind it and one visitor’s timeline.

AI revenue questions FAQ

Which AI assistants can answer these questions?

Any assistant that connects to an MCP server over Streamable HTTP, such as claude.ai, Claude Code and ChatGPT with developer mode on. Setup for each is in the MCP server docs.

Can the assistant change my data?

No. Virling’s MCP server only reads: no tool adds or changes sites, goals, keys or payments, and connected apps can be revoked in account settings.

Can it tell me my ROAS or cost per click?

No. The MCP tools return visitors, payments and revenue, not ad spend, so ask which channel brings revenue and how much each visitor is worth.

Does the assistant see who my customers are?

No. Visitors are IDs and generated names; there are no names, emails or IP addresses to return.
