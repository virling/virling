    How the influencer UTM link generator works

    1. Enter the full URL of the page the creators will send people to, starting with https://.
    2. Name the campaign, such as Spring Launch. Leave it empty if you want one row per creator across every campaign.
    3. Pick the platform. A creator who posts on two platforms needs a link for each, so run the list again with the second platform.
    4. Paste the names or handles. Copy each link to its creator, or download the CSV and keep it next to your briefs.

    Names become lowercase, accents and a leading @ are dropped, and spaces, dots and underscores turn into single hyphens. Letters from other alphabets are kept. With the defaults above, Jane Doe gets:

    https://example.com/products/starter-kit?utm_source=instagram&utm_medium=influencer&utm_campaign=spring-launch-jane-doe

    @sam.lee becomes spring-launch-sam-lee and Ana Ruíz becomes spring-launch-ana-ruiz. The creator goes in utm_campaign because Virling groups revenue by campaign. utm_content is stored with the visit but has no report row. If one creator gets several links on one platform, add utm_content yourself, such as reel or bio, in the UTM builder.

    What gets flagged in the list

    • A duplicate name. The second copy is left out, so you do not hand out the same link twice.
    • Two names that clean to the same value. jane.doe and Jane Doe both become jane-doe. They may be two people, and their sales would share one row. The first keeps its link and the second waits until you change it.
    • An empty name, such as a blank line in the middle of the list, or two commas in a row.
    • A name with no letters or numbers, such as a line of emoji or dashes.
    • A campaign value over 200 bytes. Virling keeps the first 200 bytes of a tag, so longer values could end up the same.

    The channel Virling gives each platform

    Virling reads the medium first. influencer is not a paid or email medium, so it does not decide the channel. The referrer does when the browser sends one, and the utm_source does when it does not. These are the channels for a click with no referrer, or with the platform itself as the referrer.

    Keep cpc, paidsocial and email out of these links. Those mediums move the visit into Paid or Email whatever the platform. If you run ads with a creator's video, make a separate link for the ad and use a paid medium there.

    Use links and discount codes together

    A link and a code answer different questions. The link counts every visit the creator sent and which of those visitors paid, with or without the code. It misses followers who never click. The code counts everyone who types it at checkout, including someone who heard it and came back on a laptop. It misses buyers who skip it, and it counts strangers when it leaks.

    Give each creator both, with matching names: the link ending in jane-doe and a code such as JANEDOE. Virling credits each payment to the visit before it and does not read discount codes, so code uses come from your store's report. Here is how the two look side by side.

    Before you send the links

    1. Open one link in a private window. The page should load with every tag still in the address bar. If a redirect drops them, see UTM parameters lost after redirect.
    2. Paste a link into the UTM checker to look for mistakes, and into the traffic source checker to see its channel with different referrers.
    3. Ask each creator to paste the whole link. If they post your plain URL, the visit can be credited to the platform at best, not to them.
    4. If a link has to be short, shorten the tagged one, and check that the tags are still there after the redirect.

    Influencer UTM link FAQ

    How do I make UTM links for influencers?

    Enter the landing page, a campaign name and the platform, then paste the creator names, one per line. Each creator gets a link with the platform as utm_source, influencer as utm_medium, and the campaign name plus their own name as utm_campaign.

    Should the creator go in utm_campaign or utm_content?

    In Virling, use utm_campaign. It groups revenue by campaign, and utm_content is stored but is not a report row. If your other reports need one campaign name for the whole launch, make those links in the bulk UTM builder instead and put the creator in utm_content.

    Which channel do influencer links count in?

    With utm_medium=influencer and no referrer, Virling uses the source: instagram, tiktok and youtube are Social, reddit is Communities, and twitch and snapchat are Referral. A referrer from another site decides first, so a link copied into a blog post counts as Referral.

    Do I need a discount code if each creator has a link?

    A code is still useful. It catches followers who never click and type your plain URL later. A link counts the visits and the buyers who skip the code. Give each creator both, and compare the two numbers instead of adding them, because one buyer can be in both.

    Can two creators share one link?

    No. Visits and payments from both would land in one row, and nothing can split them afterwards. This tool flags repeated names and names that clean to the same value, such as Jane Doe and jane.doe.

    Are the creator names sent anywhere?

    No. The links and the CSV are made in your browser with plain JavaScript, and nothing you paste is sent or saved.
