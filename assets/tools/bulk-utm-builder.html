How the bulk UTM builder works

  1. Paste your links, one per line. Each line must be a full URL starting with https://.
  2. Fill in the source, medium and campaign once. They are added to every link, the same way the UTM builder does for one link: spaces become hyphens and values are lowercased unless you untick the box.
  3. To tag rows differently, paste a CSV instead. The first line names the columns: url is required, and source, medium, campaign, content and term (or utm_source and so on) are optional.
  4. Copy all the tagged links, or download a CSV with the original URL, the tagged URL and the result for each row.

Query strings already on a link are kept, and the tags go before any #fragment, so https://example.com/#features becomes https://example.com/?utm_source=newsletter&utm_medium=email&utm_campaign=october-launch#features. A line that is not a full URL, or a row left without a source, is flagged in the results and left out of the copied links, not dropped silently.

Common input problems

A link without https://, such as example.com/signupFlags it as not a full URL and leaves it out of the copied links. The CSV download keeps the row with its error.
mailto: and other links that are not web pagesFlags them the same way. Only http and https links are tagged.

Name tags consistently and check the results

  • Agree the names before you tag. Pick one source per platform and a short, fixed list of mediums. The UTM naming template gives you a table to fill in and share.
  • Lowercase with hyphens. Newsletter and news letter become separate rows in most reports; this builder writes newsletter and news-letter.
  • Use utm_content to tell links apart. When one email or page has several links, give each a content value such as header-button or footer-link.
  • Do not tag links between your own pages. The tag replaces the visitor's real source.
  • Start from clean links. Remove old tags and click IDs with the URL cleaner before you paste your list.
  • Printing a link instead? The QR code generator with UTM tags makes one tagged code per placement.
  • Check the list before it goes out. Paste the tagged links into the UTM checker to catch capitals, spaces, missing mediums and tags after the #. To read the tags back into columns, use the bulk UTM parser.

Bulk UTM builder FAQ

How do I add UTM tags to many links at once?

Paste the links one per line, fill in the source, medium and campaign, and copy all the tagged links. For different tags per link, paste a CSV with a url column and a column for each tag.

What CSV format does it accept?

A header row with a url column, plus any of source, medium, campaign, content and term, separated by commas. Cells with commas can be wrapped in double quotes, as spreadsheet exports do.

What happens to links that already have a query string or a #fragment?

The existing parameters are kept and the UTM tags are added after them. A fragment stays at the end of the link, after the tags, so analytics tools still read them.

What if a line is not a valid URL?

It stays in the results, marked as not a full URL, and is left out of the copied links. The CSV download keeps it with its error so you can fix it.

Are my links sent anywhere?

No. The links are built in your browser with plain JavaScript, and the CSV is created on your device.
