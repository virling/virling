How to make a QR code with UTM tags

  1. Paste the full URL of the page the scan should open, such as https://example.com/spring.
  2. Keep utm_source as qr, so all your codes group under one source.
  3. Keep utm_medium as print, or pick another value and use it for every code.
  4. Set utm_campaign to the one place this code will be, such as a flyer or a booth banner.
  5. Download the SVG or PNG, scan it with a phone and check the address it opens before you print it.

Why a QR code needs UTM tags

A phone camera opens the link with no page before it, so the visit usually has no referrer. Without a tag, analytics tools count it as Direct, next to people who typed your address. A tag travels inside the link. In Virling, a scan with utm_source=qr, utm_medium=print and no referrer counts as Referral, under its own source and campaign. The rules are in how channels are decided.

A worked example

This shop and its codes are an example. It prints a spring flyer, and the code should open https://example.com/spring. With the source qr, the medium print and the campaign qr-spring-flyer, the code holds this link:

https://example.com/spring?utm_source=qr&utm_medium=print&utm_campaign=qr-spring-flyer

That is 86 characters, which fits a version 6 code of 41 by 41 modules. The shop also puts the link on a window poster and on a card in each parcel. Each gets its own campaign and its own code:

  • Flyer: qr-spring-flyer
  • Window poster: qr-window-poster
  • Parcel card: qr-parcel-card

All three open the same page, and the report shows three rows. With one shared code, the three would add up into one row for good.

What to check before you print

  • Keep the white border. The files include a border of four modules on each side. Scanners use it to find the code, so do not crop it or print over it.
  • Keep it dark on light. Some scanners do not read a light code on a dark background.
  • Keep the link short. Every version adds four modules to each side. The generator goes up to version 20, which holds 666 characters, but a short link is easier to scan when the code is small or far away.
  • Know what the code survives. These codes use error correction level M, which can restore about 15% of the code when it is dirty or damaged.
  • Point it at a page on your site. A code that opens a payment link directly skips the page that records the visit, so the sale cannot be credited to the scan.

questions

QR code and UTM FAQ

How do I make a QR code with UTM tags?

Paste the page URL into the generator above, set the source, the medium and the campaign, and download the code as SVG or PNG. The tags are part of the link inside the code, so every scan opens the page with them.

Which UTM tags should a QR code use?

Use utm_source=qr, one fixed medium such as print, and a campaign that names the placement, such as qr-spring-flyer. Avoid a medium such as email or cpc, because Virling counts those as Email and Paid.

Does a QR code made here expire?

No. The code holds the tagged link itself, with no redirect in between, so it works for as long as the page does. For the same reason it cannot be edited: to change the link, make and print a new code.

Do UTM tags make a QR code harder to scan?

They can. A longer link needs more modules, which are the small squares of the code, so each one is smaller at the same print size. Keep the values short, print the code larger, or put a short link that redirects to the tagged URL in the code.

Should I download SVG or PNG?

Use SVG for print and design tools, because it stays sharp at any size. Use PNG where SVG is not accepted, such as some documents, slides and messages. The PNG is at least 1,024 pixels wide.

Is my link sent anywhere?

No. The tagged link, the QR code and both files are made by a script in this page. The link is not sent to Virling or to any other server.
