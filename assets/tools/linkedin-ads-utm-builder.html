Fixed and dynamic parameters

LinkedIn calls them static and dynamic URL tracking parameters. A key and its value are joined with an equals sign, and parameters are joined with an ampersand:

Fixed parameterDynamic parameter
What it holdsA value you type, the same on every clickA value LinkedIn fills in, such as a campaign name or ID
How it looksutm_source=linkedinutm_campaign={{CAMPAIGN_NAME}}
Where it can be setAccount, campaign and ad levelAccount or campaign level
Use it forutm_source and utm_mediumutm_campaign and utm_content

A dynamic value must be in capital letters with double curly brackets before and after it. LinkedIn lists letters, numbers and underscores as supported in keys, and the plus sign and hyphen as well in values. This builder is stricter with the source and medium: it leaves out the plus sign, because a plus in a query string is read as a space.

The parameters do not replace the ones already in the destination URL. LinkedIn says the full set is a combination of the account, campaign and ad level parameters, so keep each tag in one place. The builder warns you when the landing page already carries a tag it is about to add.

Sources, all read on 2026-11-25: LinkedIn Help, URL tracking parameters in Campaign Manager, Changes to campaign hierarchy in Campaign Manager and Create an ad set in Campaign Manager; LinkedIn API docs, Dynamic UTM Tracking.

New and old parameter names

Starting in October 2025, LinkedIn renames two of the four levels in Campaign Manager: a campaign group becomes a campaign, and a campaign becomes an ad set. Creative parameters become ad parameters. The change is gradual, so you might not see the new terms yet.

This matters because two names are used on both sides. {{CAMPAIGN_NAME}} and {{CAMPAIGN_ID}} used to mean what is now the ad set, and now mean what was the campaign group. LinkedIn says existing ad sets are updated to the new values by themselves while the key stays the same, and that new or edited ad sets must use the new ones.

If your account shows ad sets, leave the last box empty. If it still shows campaign groups, tick it. Your choices stay on the same level and only the names in the string change. An old tag list or a template saved before the rename is worth checking by hand.

Which UTM tag each LinkedIn parameter fits

The names are from LinkedIn Help, URL tracking parameters in Campaign Manager and Changes to campaign hierarchy in Campaign Manager, read on 2026-11-25. The last column is our mapping, and the one this builder uses.

New parameterOld parameterUTM tag
{{CAMPAIGN_NAME}}{{CAMPAIGN_GROUP_NAME}}utm_campaign
{{CAMPAIGN_ID}}{{CAMPAIGN_GROUP_ID}}utm_campaign, if the campaign name is off
{{AD_SET_NAME}}{{CAMPAIGN_NAME}}utm_campaign if both campaign boxes are off, or utm_content if both ad boxes are off
{{AD_SET_ID}}{{CAMPAIGN_ID}}The same as the ad set name, if that is off
{{AD_NAME}}{{CREATIVE_NAME}}utm_content
{{AD_ID}}{{CREATIVE_ID}}utm_content, if the ad name is off
{{ACCOUNT_NAME}}{{ACCOUNT_NAME}}None, sent as account_name
{{ACCOUNT_ID}}{{ACCOUNT_ID}}None, sent as account_id

There is no keyword in LinkedIn’s list, so the builder leaves utm_term out. If you tick both the name and the ID of one level, the ID is sent under its own key, such as campaign_id.

A name is easy to read in a report, but a campaign that is renamed becomes a new row. An ID stays the same and has to be looked up. LinkedIn’s pages do not say how spaces or symbols in a name are written into the URL, so plain names such as demo-cfo-q4 are the safe choice.

Where to paste it in Campaign Manager

  1. Copy the parameter string, with no question mark in front.
  2. Create an ad set. Adding URL tracking parameters for the ads in it is one of the optional steps. If your account still has the old names, this is a campaign.
  3. Paste the string into the URL tracking parameters and save.
  4. Keep the landing page URL in the ad itself free of the same tags.
  5. Click through from an ad and check that the tags are still in the address bar once the page has loaded. A redirect on your own site can drop them.

LinkedIn’s help page shows a dynamic value under the key campaign_id, and has no example with a UTM key. Its API docs do show utm_campaign filled with CAMPAIGN_NAME, though still with the old level names. So test one ad before you roll the string out. If Campaign Manager does not accept it, type the campaign name in place of the part in curly brackets.

The API docs also say dynamic tracking does not support Conversation Ads and Message Ads. For those, put a fully tagged link in the message. The UTM builder makes one.

A worked example

With the defaults above, the string is utm_source=linkedin&utm_medium=paid_social&utm_campaign={{CAMPAIGN_NAME}}&utm_content={{AD_ID}}.

If the landing page is https://example.com/pricing, the campaign is named demo-cfo-q4 and the ad ID is 123456789, the visitor lands on https://example.com/pricing?utm_source=linkedin&utm_medium=paid_social&utm_campaign=demo-cfo-q4&utm_content=123456789. These values are invented. With first-party cookies on, LinkedIn also adds a li_fat_id (LinkedIn Help, Troubleshoot implementing first-party cookies on your website, read on 2026-11-25). The preview leaves it out because its value only exists for a real click.

What Virling reads from these tags

Virling reads utm_source, utm_medium, utm_campaign, utm_content and utm_term from the landing URL to find the channel and campaign, and not the li_fat_id. It only checks whether a li_fat_id is there, so that a Direct visit can be labelled a shared link. Parameters sent under their own name, such as account_id, are for other tools: Virling does not store them.

The builder defaults to utm_medium=paid_social so the visit is Paid. The values cpc, ppc, paid, paidsearch, paid_social and paidsocial all count as Paid and are checked before the referrer. Without one of them, a click from linkedin.com is sorted as Social, next to your unpaid posts. The full rules are in how channels are decided.

The campaign tag is the one to get right, because Virling groups revenue by it. The UTM naming convention template helps you keep one style; it writes the medium as paidsocial, which is Paid too, so pick one of the two. LinkedIn Ads revenue tracking goes from the tag to the payment, LinkedIn revenue tracking covers unpaid posts, and B2B SaaS attribution covers payments that come months after the click.

questions

LinkedIn dynamic UTM parameters FAQ

Can LinkedIn fill in utm_campaign with the campaign name?

LinkedIn's API docs show utm_campaign filled with CAMPAIGN_NAME. The Campaign Manager help page shows dynamic values under keys such as campaign_id and has no utm_campaign example, so save it and test one ad. If it is not accepted, type the campaign name as a fixed value.

Which dynamic parameters does LinkedIn support?

The new list is ACCOUNT_ID, ACCOUNT_NAME, CAMPAIGN_ID, CAMPAIGN_NAME, AD_SET_ID, AD_SET_NAME, AD_ID and AD_NAME. Each one goes in capital letters between double curly brackets, such as {{CAMPAIGN_ID}}. An account that has not switched yet still shows campaign group and creative names.

Why did CAMPAIGN_NAME change meaning?

Starting in October 2025, LinkedIn renamed campaign groups to campaigns and campaigns to ad sets. In the new naming CAMPAIGN_NAME is the name of what was a campaign group, and AD_SET_NAME is the name of what was a campaign.

Where do I add URL parameters in Campaign Manager?

LinkedIn lists an optional step to add URL tracking parameters while you create an ad set, and says dynamic parameters can be added at the account or campaign level. Paste the string without a question mark in front.

Which utm_medium should LinkedIn ads use?

Use a medium your analytics counts as paid. Virling counts paid_social, paidsocial, paid, cpc, ppc and paidsearch as Paid. With social, a click from linkedin.com is Social, next to your unpaid posts.

Does Virling read the li_fat_id?

Virling reads the UTM tags to find the channel and campaign, not the li_fat_id. It only checks whether a li_fat_id is there, so a Direct visit can be labelled a shared link. Leave it on the URL for LinkedIn.
