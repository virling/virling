How to export subscriptions from Stripe

In the Stripe Dashboard, open Subscriptions, filter to the subscriptions you want and click Export. Pick the custom column set and include all columns rather than the default set, so the file has the billing interval, interval count and quantity as well as the amount. Then drop the CSV above.

How the calculator reads the file

Stripe does not publish a fixed list of column names for this export, so columns are found by meaning. The header row is read without regard to case, spaces or underscores, and the page shows which column it used for each field:

FieldColumn it looks for
StatusA header containing “status”. Required.
AmountA header containing “amount”, skipping discount, tax, fee and balance amounts. The price of one unit. Required.
IntervalA header containing “interval” but not “count”: day, week, month or year. Required.
Interval countA header containing “interval” and “count”, as in billed every 3 months. If missing, every row counts as 1.
QuantityA header containing “quantity”, such as seats. If missing or blank, 1.
CurrencyA header containing “currency”. If missing, all rows are read as one currency.

If a required column is not found, the page names it and asks you to export again with all columns.

How MRR is counted

  1. Only rows with status active or past_due count. A past due subscription is one whose renewal failed while Stripe retries the card, so it stays in until it ends. Canceled, incomplete, incomplete expired, trialing, unpaid and paused rows are left out, and the page lists how many rows had each status.
  2. Each row's charge is amount × quantity.
  3. The charge is turned into a monthly amount: a yearly plan is divided by 12, a weekly plan is multiplied by 52 / 12 and a daily plan by 365 / 12, and the result is divided by the interval count. A $90 plan billed every 3 months adds $30 of MRR.
  4. MRR is added up per currency, never converted between currencies. ARR is MRR × 12, and ARPU is MRR divided by the subscriptions counted.

Amounts can be written in whole units (49.00) or in the smallest unit, as the Stripe API does (4900). The switch above picks one; it starts on whole units when the amounts have a decimal point and on cents when they do not. Currencies with no minor unit, such as JPY and KRW, are never divided by 100.

The amount column holds the list price, so discounts and coupons are not taken off, and a subscription with several prices may need to be checked by hand. Virling counts MRR at list price before discounts and tax too; see how Virling counts MRR.

A worked example

The made-up example above is not data from a real business. Three subscribers pay $20 a month ($60), two pay $50 a month for 3 seats each ($300), one pays $480 a year ($40), one past due subscriber pays $50 a month ($50), one pays $90 every 3 months ($30) and one pays $10 a week ($10 × 52 / 12 = $43.33). That is $523.33 of MRR from 9 subscriptions, an ARPU of $58.15. The trialing, canceled and incomplete rows add nothing.

Stripe MRR calculator FAQ

Is my Stripe export uploaded?

No. The CSV is read by JavaScript in your browser and nothing in it is sent anywhere. You can disconnect from the internet after the page loads and it still works.

Which subscriptions count toward MRR?

Active and past due ones. Canceled, incomplete, incomplete expired, trialing, unpaid and paused subscriptions are left out, because they are not billing a recurring amount right now.

How are yearly and weekly Stripe plans counted?

As a monthly amount. A yearly price is divided by 12, a weekly price is multiplied by 52 / 12, and if a plan bills every few intervals the result is divided by that count.

Why does my MRR not match the Stripe Dashboard?

This page uses the list price times quantity, so discounts are not taken off, and it does not convert between currencies. Stripe's own figures can treat discounts, taxes and paused subscriptions differently.

Can the export show which channel brought each subscriber?

No. The export has no record of the visit before the payment. Virling joins each Stripe payment to that visit and keeps the channel on every renewal, so you can see MRR by channel.
