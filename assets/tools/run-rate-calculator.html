The run rate formula

Annual run rate is the revenue from one period times the number of those periods in a year:

annual run rate = period revenue × periods per year

That is 52 for a week, 12 for a month and 4 for a quarter. The recurring run rate does the same with only the revenue that will come back next period:

recurring run rate = period revenue × (1 - one-time share) × periods per year

The gap between the two is the one-time revenue scaled to a year, which is the part of the headline number that assumes a one-off sale happens again every period.

A worked example

With the defaults above, a month brought in $25,000, so the annual run rate is $25,000 × 12 = $300,000.

20% of that month, $5,000, was one-time: setup fees and a few one-off orders. The recurring part is $20,000, so the recurring run rate is $20,000 × 12 = $240,000. One-time revenue adds $60,000 to the headline, which puts it 25% above what recurs.

The same business measured by the week might see $6,000 in a normal week, a run rate of $6,000 × 52 = $312,000. A week with one large one-off order of $4,000 would show $10,000 × 52 = $520,000, which is why a short period with one-time revenue in it can overstate run rate a lot.

Why run rate by acquisition channel matters

Run rate is one total. It does not say which marketing brought the revenue, or whether the channels behind it bring customers who pay again or customers who buy once. Two businesses with the same run rate can be in very different places: one whose best channel brings subscribers who renew, the other whose best channel brings one-off buyers whose revenue will not recur. Split run rate by the channel that first brought each customer and you can see which channels build recurring revenue and which only lift a single period. To get it, each payment has to be joined to the visit that brought the customer. Run rate calculator FAQ

How do you calculate revenue run rate?

Take the revenue from one period and multiply it by the number of those periods in a year: weekly revenue times 52, monthly revenue times 12 or quarterly revenue times 4.

What is the difference between run rate and ARR?

ARR counts only recurring subscription revenue, so it is MRR times 12. Run rate annualizes all revenue in a period, one-time sales included. For a business whose revenue is all subscriptions the two match; the more one-time revenue a period has, the further run rate sits above ARR.

Why does one-time revenue inflate run rate?

Run rate assumes every period repeats. A setup fee, a large one-off order or a lifetime deal in the period you measure gets multiplied as if it will come in again every week, month or quarter, which it may not. The recurring run rate leaves it out.

Which period should I use?

The most recent full period that looks normal. A week reacts fastest but swings with launches and holidays; a quarter is steadier but older. A month is the usual middle ground.

Is run rate a forecast?

No. It is the current period scaled to a year, with no growth, churn or seasonality. Treat it as a size check, not a prediction of next year's revenue.
