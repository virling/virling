Final URL suffix or tracking template

Both fields sit under URL options in Google Ads, and both accept ValueTrack parameters, which Google replaces with details of the click. They do different jobs:

Final URL suffixTracking template
What you enterParameters only, such as utm_source=googleA whole URL with a tag that inserts the final URL, such as {lpurl}
What it doesAttaches the parameters to the end of the landing page URLBuilds the URL from the template, which can send the click through a tracker
With parallel trackingThe visitor lands on the final URL with the suffix on itThe visitor goes to the final URL and the template URL loads in the background
If it is wrongA tag is missing or misspelledWith no URL tag at account, campaign or ad group level, the landing page URL breaks

For UTM tags, use the suffix. It is the field Google describes for tracking where people go after they click, and it only adds to the address of your page. Use the template when a click tracker needs it. Google’s own examples also use a template such as {lpurl}?device={device} to add parameters to the landing page, so the builder gives you that form too. Fill in one of them with these tags, not both: Google adds the suffix to the final URL first and then puts the result in place of {lpurl}, so the tags would appear twice.

A suffix or template can be set on the account and on narrower levels such as the campaign. The most specific one is used, and it replaces the broader one, so a campaign suffix has to repeat every tag you still want from the account suffix.

Which UTM tag each ValueTrack parameter fits

The names and what they return are from Google Ads Help, Set up tracking with ValueTrack parameters, read on 2026-11-25. The last column is our mapping, and the one this builder uses.

ParameterWhat it returnsUTM tag
{campaignid}The campaign IDutm_campaign, when the campaign name is empty
{creative}A unique ID for your adutm_content
{adgroupid}The ad group IDutm_content, if the ad ID is off
{assetgroupid}The asset group ID, for Performance Maxutm_content, if the ad ID and ad group ID are off
{keyword}The keyword in your account that matched; blank when the ad matched without keywordsutm_term
{targetid}The ID of the keyword, remarketing list or other target that triggered the adutm_term, if the keyword is off
{placement}The site where the ad was clicked, or the placement targeting that matched itutm_term, if the keyword and target ID are off
{matchtype}e exact, p phrase, b broad, a AI Max keywordlessNone, sent as matchtype
{network}g Google search, s search partners, d Display, ytv YouTube, x Performance Max, and othersNone, sent as network
{device}m mobile, t tablet, c computerNone, sent as device
{loc_physical_ms}The ID of the location of the clickNone, sent as loc_physical_ms

When Google cannot insert a value, the parameter is replaced with nothing, so utm_term={keyword} can arrive empty. Not every campaign type fills in every parameter. Google lists {campaignid}, {assetgroupid}, {device} and {loc_physical_ms} as fully supported in Performance Max, and says Demand Gen does not support {keyword}, {targetid}, {placement} or {network}. See also About ValueTrack parameters, read on 2026-11-25.

Where to paste it in Google Ads

  1. For the whole account, open Account settings in the Admin menu and select Tracking Template.
  2. For one campaign, open Campaigns, select the Settings tab and click the pencil in the Tracking template column.
  3. Paste the suffix into Final URL suffix, with no question mark in front, and save.
  4. Use the Test button in URL options to check that the URL still leads to your page. See test your landing page.
  5. Open the tested URL and check that the tags are still in the address bar once the page has loaded. A redirect on your own site can drop them.

A typed campaign name only makes sense on that one campaign. If you set the suffix on the account, clear the campaign name and tick Campaign ID, so every campaign gets its own utm_campaign. Google says changes to tracking templates take 24 to 48 hours to show in your ads, and that setting URL options at the ad group, campaign or account level does not send your ads back for approval.

A worked example

With the defaults above, the suffix is utm_source=google&utm_medium=cpc&utm_campaign=brand-search&utm_content={creative}&utm_term={keyword}. The template is the same text after {lpurl}?.

If the final URL is https://example.com/pricing, the ad ID is 123456789012 and the keyword is analytics, the visitor lands on https://example.com/pricing?utm_source=google&utm_medium=cpc&utm_campaign=brand-search&utm_content=123456789012&utm_term=analytics. With auto-tagging on, Google also adds a gclid (About auto-tagging, read on 2026-11-25). The preview leaves it out because its value only exists for a real click.

What Virling reads from these tags

Virling reads utm_source, utm_medium, utm_campaign, utm_content and utm_term from the landing URL, and not the gclid. Leave auto-tagging on for Google and add the UTM tags for Virling. Parameters sent under their own name, such as device or matchtype, are for other tools: Virling does not store them.

The builder defaults to utm_medium=cpc so the visit is Paid. The values cpc, ppc, paid, paidsearch, paid_social and paidsocial all count as Paid and are checked before the referrer. Without one of them, a click from google.com is sorted as Organic search, next to your unpaid visits. The full rules are in how channels are decided.

The campaign tag is the one to get right, because Virling groups revenue by it. Keep one style, a name or an ID, for every campaign: the same campaign tagged two ways becomes two rows. The UTM naming convention template helps you write the list down, and Google Ads revenue tracking shows how to go from the tag to the payment.

Google Ads tracking template FAQ

What is the difference between a final URL suffix and a tracking template?

A final URL suffix holds only parameters, and Google Ads attaches them to the end of your landing page URL. A tracking template is a whole URL that needs a tag such as {lpurl} to insert the final URL, and it can point at a click tracker first. For UTM tags alone, the suffix is the simpler field.

What should a Google Ads tracking template for UTM tags look like?

Start with {lpurl}, then a question mark, then the tags joined with an ampersand: {lpurl}?utm_source=google&utm_medium=cpc&utm_campaign=brand-search. If the final URL already has a question mark, Google Ads replaces the one in the template with an ampersand.

Should I fill in both the suffix and the tracking template?

Not with the same tags. Google adds the suffix to the final URL and then puts that URL into the template, so each tag would appear twice. Put UTM tags in the suffix, and keep the template for a click tracker if you use one.

Is there a ValueTrack parameter for the campaign name?

Google's list has {campaignid}, which returns the campaign ID, and no parameter for the campaign name. To see a readable name, type it in a suffix set on that campaign. To cover the whole account with one suffix, use the ID and look it up later.

Do I need UTM tags if auto-tagging is on?

Yes, for any tool that does not read the gclid. Auto-tagging adds a gclid that Google can look up. Virling reads utm_source, utm_medium and the other UTM tags and not the gclid, so use both on the same ads.

Why does my Google Ads traffic show as organic search?

The landing URL had no paid medium. Without utm_medium=cpc, Virling sorts a click that arrives from google.com by its referrer, which is Organic search. With it, the visit is Paid, because the medium is checked before the referrer.
