    How to make an llms.txt file
    

    1. Enter the site name and a one-line summary that makes sense to someone who has never seen the site.
    2. Add the pages that answer real questions, grouped in sections such as Docs, Products or Policies. Give each link a title and a short description. Or paste your URLs and edit the guessed titles.
    3. Use the buttons to reorder sections and links, with the most useful first. Put secondary pages in a last section named Optional.
    4. Copy or download the file, put it at /llms.txt on your domain, and open that address to check that it loads as plain text.
    

    What the llms.txt format looks like
    

    The llms.txt proposal describes a Markdown file with its parts in this order:
    

    • A heading with the site name. One # line. This is the only required part.
    • A summary. A quote line starting with >.
    • Details. Optional paragraphs or lists, without headings. This tool does not write them; add them by hand below the summary if you need them.
    • Sections of links. A ## heading, then one link per line, with an optional colon and description.
    

    A worked example
    

    Example Shop is a made-up store. The button "Fill in the example" above puts in its name, its summary, a section named Shop with two links, and an Optional section with one. The result is:
    

    # Example Shop

> Example Shop sells refillable pens to small offices.

## Shop

- [Pens](https://example.com/pens): every pen, with sizes and refill types
- [Shipping and returns](https://example.com/shipping): delivery areas and how to return an order

## Optional

- [Our story](https://example.com/about)
    

    The last link has no description, so it has no colon. The proposal suggests linking to pages AI tools can read easily, such as Markdown versions, so if /pens.md exists, link to that. Keep the file short: choose pages, do not copy your sitemap.
    

    What llms.txt can and cannot do
    

    It can point an AI tool to the right pages once the tool looks for it. It cannot make an assistant read your site or recommend it, and it does not control crawling. If robots.txt blocks a bot, the file does not unblock it: test yours with the AI crawler checker.     llms.txt generator FAQ
    
    
    
      
    What is an llms.txt file?
    A Markdown file that gives AI tools a short overview of a site and links to its most useful pages. It comes from a proposal published at llmstxt.org in 2024 and updated in 2026.
    
      
    Do AI assistants read llms.txt?
    Some tools do and some do not. It is a proposal, not a rule, so support varies between assistants and can change. Publishing the file does not guarantee that an assistant reads it, mentions your site or links to it.
    
      
    Where do I put the file?
    Serve it as plain text at /llms.txt on your domain, such as https://example.com/llms.txt. The proposal also allows it in a folder: /docs/llms.txt covers the pages under /docs/.
    
      
    Does llms.txt replace robots.txt or sitemap.xml?
    No. robots.txt says which automated access is acceptable and sitemap.xml lists every page for search engines. llms.txt is a short, curated list for AI tools, and it does not block or allow any bot.
    
      
    What is the Optional section for?
    By convention, a section named Optional holds links that an AI tool can skip when it needs a shorter context. Put it last and use it for secondary pages. You do not have to have one.
    
      
    Is anything I type sent anywhere?
    No. The file is built in your browser and the download is created on your device. The tool does not open your URLs, so it cannot tell you whether a link is broken.
