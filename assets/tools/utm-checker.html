What the UTM checker looks for

Each line is read as a URL. The query string after ? is split into parameters, and every parameter starting with utm_ is checked against these rules:

  • Missing source or medium. A tagged link needs both utm_source and utm_medium. Without a medium, paid and email links can blend into Referral.
  • Mixed case. Most tools treat LinkedIn and linkedin as two sources, and some do not read UTM_Source as utm_source. Values and names should be lowercase.
  • Spaces. A space, %20 or + in a value is easy to type differently next time. Use hyphens.
  • Duplicate parameters. Two utm_source values on one link make the tool pick one and drop the other.
  • UTMs after the #. Everything after # is the fragment. Browsers never send it to the server and most analytics scripts read tags from the query string only, so tags there are lost.
  • Internal links. A utm_source that names your own site, or a medium of internal, marks a link between your own pages. That tag replaces the visitor's real source.
  • Unknown or empty parameters. A typo such as utm_sorce is ignored by analytics tools, and an empty value tells them nothing.

A worked example

Take https://example.com/?utm_source=LinkedIn&utm_campaign=october-launch, the second default link above. The checker finds two problems:

  1. utm_source=LinkedIn has capitals, so these visits show up apart from every linkedin link the team tagged in lowercase.
  2. There is no utm_medium, so nothing says whether this was an organic post or a paid ad.

The fixed link is https://example.com/?utm_source=linkedin&utm_medium=social&utm_campaign=october-launch. Writing the allowed values down once, as in the UTM naming template, stops the same mistakes coming back.

UTM checker FAQ

What does a UTM checker do?

It reads the UTM parameters on a link and flags mistakes before the link goes out: a missing source or medium, capitals, spaces, duplicate parameters, tags after the # and tags on links between your own pages.

Do capitals in UTM values matter?

Yes. Most analytics tools compare values exactly, so Newsletter and newsletter become two rows in your reports. Keep every value lowercase.

Can UTM tags go after the # in a URL?

No. The part after # is never sent to the server and most analytics scripts read tags from the query string only. Put the tags after ? and before any #.

Should links between my own pages have UTM tags?

No. The tag replaces the visitor's real source with your own site, so the channel that brought them loses the credit. Use UTM tags only on links placed outside your site.

Are my links sent anywhere?

No. The check runs in your browser and nothing you paste leaves the page.
