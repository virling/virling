Fixed values and macros

A TikTok ad URL can carry two kinds of values. A key and its value are joined with an equals sign, parameters are joined with an ampersand, and the first one follows a question mark:

Fixed valueMacro
What it holdsText you type, the same on every clickA value TikTok fills in, such as a campaign name or ID
How it looksutm_source=tiktokutm_campaign=__CAMPAIGN_ID__
Use it forutm_source and utm_mediumutm_campaign, utm_content and utm_term

A macro is written in capital letters with two underscores on each side. Copy it as it is: a macro that is misspelled is just text. UTM values are case-sensitive, so TikTok warns that TikTok and tiktok can count as two sources. The builder lowercases the source and medium for that reason. TikTok also says that everything after a # in a URL is omitted, so the builder leaves that part out and tells you.

Sources, all read on 2026-11-25: TikTok Business Help Center, About UTM Parameters, How to add URL parameters to your website URL, UTM parameters best practices and About TikTok Click ID.

Which UTM tag each TikTok macro fits

The names and what they return are from TikTok, About UTM Parameters, read on 2026-11-25. The last column is our mapping, and the one this builder uses.

MacroWhat it returnsUTM tag
__CAMPAIGN_NAME__The campaign nameutm_campaign
__CAMPAIGN_ID__The campaign IDutm_campaign, if the campaign name is off
__AID_NAME__The ad group nameutm_term
__AID__The ad group IDutm_term, if the ad group name is off
__CID_NAME__The creative nameutm_content
__CID__The creative IDutm_content, if the creative name is off
__ADID_V2_NAME__The ad name, in upgraded Smart+ campaignsutm_content, if both creative boxes are off
__ADID_V2__The ad ID, in upgraded Smart+ campaignsutm_content, if both creative boxes and the Smart+ ad name are off
__PLACEMENT__The placement type, such as TikTok or TikTok PangleNone, sent as placement

The ad group goes to utm_term because that tag was made for search keywords and TikTok’s page says you can use it for your own string, such as the ad group name. If you tick both the name and the ID of one level, the ID is sent under its own key, such as campaign_id.

In the upgraded Smart+ experience, TikTok calls the bundle of creative assets the ad and says the available macros change. If you run those campaigns and want one row per ad, clear the creative boxes and tick the Smart+ ad ID. The two Smart+ macros are listed only for those campaigns, so leave them off everywhere else.

A name is easy to read in a report, but a campaign that is renamed becomes a new row. An ID stays the same and has to be looked up. TikTok’s pages do not say how spaces or symbols in a name are written into the URL, so the builder starts with IDs. If you choose names, plain ones such as spring-sale are the safe choice.

Where to paste it in TikTok Ads Manager

  1. Open the ad and go to the Ad details section.
  2. Paste the full URL into Destination URL.
  3. Click Edit under the Preview button and check Auto-attach. Turn it off if you use the tags from this page.
  4. If Autodetect is on, check that the parameters it found are the ones you pasted.
  5. Click Preview next to the URL to open the page in a browser, and check that the tags are still in the address bar once it has loaded. A redirect on your own site can drop them.

You can also type the same values by hand: under URL, click Build URL parameters, fill in the UTM fields, add other keys under Custom parameters and click Apply. TikTok says a copied ad keeps its URL and parameters, and that an existing ad can be edited.

Auto-attach is TikTok’s own way to add tags. It fills in the campaign source (TikTok), the medium (Paid), an ID and a name. Virling compares the medium without regard to case, so those clicks are Paid as well. TikTok’s page does not say what happens when the URL already has the same tags, and its best practices say an analytics tool may keep only the last of a repeated key. Use one method per ad. The UTM checker reads a finished URL and shows which tags it carries.

A worked example

With the defaults above, the URL is https://example.com/pricing?utm_source=tiktok&utm_medium=paid_social&utm_campaign=__CAMPAIGN_ID__&utm_content=__CID__&utm_term=__AID__.

If the campaign ID is 1700000000000001, the creative ID is 1700000000000003 and the ad group ID is 1700000000000002, the visitor lands on https://example.com/pricing?utm_source=tiktok&utm_medium=paid_social&utm_campaign=1700000000000001&utm_content=1700000000000003&utm_term=1700000000000002. These values are invented. TikTok can also append a ttclid when someone clicks the ad (About TikTok Click ID, read on 2026-11-25). The preview leaves it out because its value only exists for a real click.

What Virling reads from these tags

Virling reads utm_source, utm_medium, utm_campaign, utm_content and utm_term from the landing URL to find the channel and campaign, and not the platform’s click ID, the ttclid. It only checks whether a ttclid is there, so that a Direct visit can be labelled a shared link. Parameters sent under their own name, such as placement, are for other tools: Virling does not store them.

The builder defaults to utm_medium=paid_social so the visit is Paid. The values cpc, ppc, paid, paidsearch, paid_social and paidsocial all count as Paid and are checked before the referrer and the in-app browser. Without one of them, a click from tiktok.com or from inside the TikTok app is sorted as Social, next to your unpaid posts. TikTok’s page also names cpm, banner and video as mediums; Virling does not count those as Paid. The full rules are in how channels are decided.

The campaign tag is the one to get right, because Virling groups revenue by it. The UTM naming convention template helps you keep one style. TikTok Ads revenue tracking goes from the tag to the payment, and influencer revenue tracking covers the links you give to creators, which should not carry a paid medium unless you want them counted with your ads.

TikTok ads UTM parameters FAQ

How do I add UTM parameters to TikTok ads?

Put them in the destination URL of the ad. In the Ad details section of TikTok Ads Manager, paste a URL that already carries the tags, or enter the plain URL, click Edit under the Preview button, then Build URL parameters, fill in the fields and click Apply.

Which macros does TikTok support in a URL?

TikTok lists __CAMPAIGN_NAME__, __CAMPAIGN_ID__, __AID_NAME__ and __AID__ for the ad group, __CID_NAME__ and __CID__ for the creative, and __PLACEMENT__. For upgraded Smart+ campaigns it also lists __ADID_V2_NAME__ and __ADID_V2__ for the ad.

Which utm_medium should TikTok ads use?

Use a medium your analytics counts as paid. Virling counts paid_social, paidsocial, paid, cpc, ppc and paidsearch as Paid. With cpm or video, a click from tiktok.com is Social, next to your unpaid posts.

Should I use the campaign name or the campaign ID?

A name is easy to read, but a renamed campaign becomes a new row in your reports. An ID stays the same and has to be looked up. Pick one and use it in every ad, because the same campaign tagged two ways becomes two rows.

Should I turn off Auto-attach when I paste my own tags?

It is the simple way to avoid duplicates. TikTok says Auto-attach fills in the source, medium, ID and name, and its help page does not say what happens when the URL already has those tags. Use one or the other and read the URL in the preview.

Does Virling read the ttclid?

Virling reads the UTM tags to find the channel and campaign, not the ttclid. It only checks whether a ttclid is there, so a Direct visit can be labelled a shared link. Leave it on the URL for TikTok.
