How the UTM parser works

  1. Paste your links, one per line. Blank lines are skipped, and lines after the first 2,000 links are not read.
  2. Each line must be a full URL starting with http:// or https://. Other lines are listed with their line number, so you can find and fix them.
  3. The part between ? and # is split into parameters. Names match in any case, and %20 and + in a value are shown as spaces.
  4. When a parameter appears twice, the first value that is not empty is used. A parameter that is missing leaves an empty cell.
  5. Copy the table to paste it into a spreadsheet, or download it as a CSV with the original URL next to the parsed columns.

What each column holds

ColumnRead from
Sourceutm_source, where the link was shared
Mediumutm_medium, the kind of channel
Campaignutm_campaign, the push the link belongs to
Contentutm_content, which link or ad was clicked
Termutm_term, often a paid search keyword
Refref, a short tag some sites add in place of UTM tags
Clean URLThe link without ref and without any parameter starting with utm_

Tags after the # are not parsed, since most analytics tools read tags from the query string only. They stay in the clean URL as part of the fragment.

A worked example

Take the second example link above. The names and values are made up for the example:

https://example.com/?plan=pro&utm_source=linkedin&utm_medium=social&utm_campaign=example-launch#faq
  • Source is linkedin, medium is social and campaign is example-launch.
  • Content, term and ref are empty, since the link does not have them.
  • Clean URL is https://example.com/?plan=pro#faq. plan is not a tracking tag, so it stays.

In the CSV the row looks like this:

url,utm_source,utm_medium,utm_campaign,utm_content,utm_term,ref,clean_url
https://example.com/?plan=pro&utm_source=linkedin&utm_medium=social&utm_campaign=example-launch#faq,linkedin,social,example-launch,,,,https://example.com/?plan=pro#faq

Bulk UTM parser FAQ

What does a UTM parser do?

It reads the query string of a tagged link and splits out the UTM parameters: source, medium, campaign, content and term. This one also extracts ref and gives you the URL without those tags.

How do I extract UTM parameters from many URLs at once?

Paste the URLs one per line, up to 2,000 at a time. Each URL becomes one row of the table, which you can copy into a spreadsheet or download as a CSV file.

What is removed from the clean URL?

Every parameter whose name starts with utm_, and ref. Other parameters, click IDs such as gclid and the # part stay as they were.

What happens to lines that are not URLs?

They are listed under the table with their line number and left out of the copied table and the CSV. A full URL starts with http:// or https://.

Why do some CSV cells start with an apostrophe?

A cell that starts with =, +, - or @ can run as a formula when a spreadsheet opens it. The parser puts an apostrophe in front so the cell is read as text.

Are my links sent anywhere?

No. The links are read in your browser with plain JavaScript, and the CSV is created on your device.
