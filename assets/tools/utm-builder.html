How to build a UTM link

  1. Start from the exact page you want people to land on, such as https://example.com/pricing.
  2. Set utm_source to where the link will live: newsletter, reddit, linkedin.
  3. Set utm_medium to the kind of channel: email, social, cpc.
  4. Set utm_campaign to the launch or promotion, so every link from it groups together.
  5. Copy the link and use it only in that one place. A new place gets a new source.

The result looks like https://example.com/pricing?utm_source=newsletter&utm_medium=email&utm_campaign=october-launch.

Common UTM mistakes

  • Tagging links between your own pages. The tag replaces the visitor's real source with an internal one and starts a new session.
  • Mixed case and spaces. Newsletter, newsletter and news letter become three rows in most tools.
  • Two names for one thing. Pick email or e-mail once and write the list down.
  • Leaving out the medium. A source alone tells you where, not what kind of channel, so paid and email links can blend into Referral.
  • Tagging organic search results. Search engines already send a referrer, so tags add nothing there.
  • Untagged links where the referrer is lost. Email, chat, PDFs, QR codes and some apps send none, so those visits count as Direct.

UTM builder FAQ

How do I build a UTM link?

Add ?utm_source=, &utm_medium= and &utm_campaign= to the page URL with a value for each, or fill in the builder above and copy the result. If the URL already has a query string, the tags are added after it with &.

What are UTM parameters?

Tags added to a link, such as ?utm_source=newsletter&utm_medium=email. Analytics tools read them from the landing URL to know where the visit came from, even when the browser sends no referrer.

Which ones do I need?

Source and medium are enough for most links. Add a campaign to group links from one launch or promotion. Term and content are for ad keywords and telling two links in the same email apart.

Should values be lowercase?

Yes. Many tools treat Newsletter and newsletter as two sources. Lowercase values and hyphens instead of spaces keep reports clean.

Where do UTM links matter most?

Places that hide the referrer: email, Discord, Slack, PDFs, QR codes and some apps. Without tags those visits look like direct traffic.
