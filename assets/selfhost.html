Click any payment to see the visits before it: where they first came from, what they read, and what made them buy.

Credit goes to the last channel that wasn't direct, or the first touch if you prefer. Renewals keep the source of the first payment.

One file. No Postgres, no ClickHouse, no Redis.

Download it, start it, add the script tag. Events and settings live in embedded storage next to the binary, so a backup is a file copy.

# download for Linux or macOS from
# github.com/virling/virling/releases
$ tar xzf virling-v0.1.0-x86_64-unknown-linux-gnu.tar.gz
$ ./virling serve --app

# then add one tag to your site
<script defer src="https://stats.you.com/v.js"
        data-site="you.com"></script>
$ docker run -d -p 8080:8080 \
    -v virling:/data \
    ghcr.io/virling/virling:latest serve --app
