# Setup

1. Add the plugin.
2. Enter your Virling server URL when asked: `https://beta.virling.com` if you use hosted Virling, or your own HTTPS URL if you self-host.
3. Sign in to Virling when Claude asks, and click **Allow**. No API key is needed.

Self-hosted servers need a public `https` address for sign-in. The CLI and HTTP API are documented at https://docs.virling.com/reference/api.html.
