# Setup

1. Add the plugin.
2. Sign in to Virling when Claude asks, and click **Allow**. No API key is needed.

The plugin connects to hosted Virling at https://beta.virling.com. If you self-host, add your own server in Claude as a custom connector with the URL `https://your-server/mcp` instead; it needs a public `https` address for sign-in. The CLI and HTTP API are documented at https://docs.virling.com/reference/api.html.
